# 課文繪本化，極簡手繪色鉛筆風

Use this skill when a user wants supplied reading material turned into a picturebook-like visual sequence, story map, paragraph summaries, theme page, or student-use comprehension worksheets. The supplied source remains the content authority; improve structure and visual clarity without inventing facts.

## Source-faithful article understanding

Read the complete supplied article or DOCX before outlining. Keep explicit source facts separate from interpretation.

Build understanding in this order:

1. Read the whole text once for its overall arc.
2. Divide it by numbered paragraphs or natural event units.
3. For each unit, record the actor, action, need or problem, object exchanged or changed, consequence, and repeated wording.
4. Track change across units: who returns, what is requested, what is given, what is lost, and how the ending echoes the beginning.
5. Compress the arc into a story map using only source-grounded nouns and actions.
6. Write one concrete paragraph summary per unit without unsupported motives, dialogue, moral judgments, or background facts.
7. Derive the overall summary from the sequence and ending. Phrase the theme as an open reading of repeated relationships, choices, and changes rather than a compulsory moral.

If a name, paragraph boundary, number, quotation, or core event is ambiguous, ask before production. Preserve the source language and exact Traditional Chinese characters when they carry meaning.

## Default picturebook structure

Unless the user specifies another structure, use:

1. Cover.
2. Story-map page showing the whole arc.
3. One page for each source paragraph or event unit, in order.
4. One page for overall story summary and theme.
5. Back cover.

For `n` source units this is normally `n + 4` pages. Lock the exact count before visual production. On every story-event page, include the approved title and the approved paragraph-summary body text. The cover and back cover may retain their approved shorter text roles.

## Locked visual language

- Pure white background: `#FFFFFF`.
- Dominant black hand-drawn line art: `#111111`, with bold outer contours, basic shapes, and only necessary interior lines.
- Add only sparse, pale colored-pencil accents: muted sage green for leaves or moss and pale warm ochre for a small number of natural objects. Keep color coverage approximately 5–10% of the page.
- Keep recurring characters, plants, and objects recognizable. Show change by simplifying or removing the same object's parts rather than changing its identity.
- Use 2–4 core visual elements per page, generous white space, and clear quiet areas for text.
- Keep the page easy for an elementary student to redraw. The story-map may contain more nodes but must remain a simple hand-drawn path.

## Typography hierarchy

- Titles use a large bold hand-drawn rounded display treatment with lively stroke variation.
- Body summaries use a clearly different, calm, highly legible Traditional Chinese book or sans treatment with comfortable line spacing.
- Never use the same font treatment for title and body. Keep title, body, section labels, and author credit in separate readable blocks.
- Render only approved text. Do not add pseudo-text, random glyphs, extra captions, page numbers, slogans, or dialogue.

## Optional comprehension worksheets

When worksheets are requested, make student actions and questions explicit rather than copying teacher-analysis language. Useful source-grounded forms include:

- Story order and causality: a word bank, ordered event path, what the character needed, what was given, and the consequence.
- Character change and theme: repeated-return table, object exchange, beginning/ending comparison, evidence lines, and an open response such as “我覺得故事提醒我們……因為……”。

Keep the worksheets printable, spacious, and answerable from the supplied text. Do not turn an interpretation into a required moral.

## Production and QA

- For image-based presentation pages, use one complete 16:9 image per page and normalize to 1920×1080 before PDF assembly.
- Freeze visible text after outline approval and keep the outline, manifest, style profile, prompts, selected images, PDF, and QA report together.
- Before delivery, verify that outline count, manifest count, selected-image count, and PDF page count agree; all page text matches the approved wording; page order follows the source; recurring objects remain consistent; background is pure white; black line art remains dominant; accents are sparse; and no page contains invented facts or unreadable text.
- If the global style changes, create a new style-profile version and a new representative sample before regenerating the full sequence.

## Boundaries

Do not use this style for watercolor, full-color, photorealistic, beige-paper, decorative-poster, or stock-image work. Do not make source-free claims sound like facts. Request the source material or mark unresolved claims for confirmation.
