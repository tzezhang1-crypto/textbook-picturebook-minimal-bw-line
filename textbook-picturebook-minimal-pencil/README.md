# 課文繪本化，極簡手繪色鉛筆風

Skill slug：`textbook-picturebook-minimal-pencil`

把使用者提供的文章、課文或 DOCX，轉成忠於原文的繪本頁面、故事大意地圖、段落大意、故事主旨，以及可選的課文理解學習單。

## 核心風格

- 背景純白（`#FFFFFF`）。
- 以黑色極簡手繪線條（`#111111`）為主。
- 只使用少量淡鼠尾草綠與淡暖赭色的色鉛筆淡彩，約占頁面 5–10%。
- 標題使用粗手繪展示字，段落內文使用清晰易讀且明顯不同的字體。
- 留白充足，每頁聚焦 2–4 個核心視覺元素。
- 不使用水彩、米白紙張、全彩、寫實或與文本無關的裝飾性素材。

## 文章理解邏輯

1. 讀完整篇文章，掌握整體事件弧線。
2. 依編號段落或自然事件單位切分文本。
3. 記錄每個單位的角色、行動、需求／問題、交換或改變的物件、結果與重複語句。
4. 追蹤誰回來、要什麼、給了什麼、失去了什麼，以及結尾如何呼應開頭。
5. 使用原文中的名詞與行動，壓縮成可讀的故事大意地圖。
6. 為每段寫具體、忠於文本的段落大意。
7. 從事件順序與結尾推導故事摘要和開放式主旨，不把解讀寫成強迫性的道德結論。

## 預設繪本結構

封面 → 故事大意地圖 → 每段／事件一頁 → 故事大意與主旨 → 封底。

若文本切成 `n` 個事件單位，預設為 `n + 4` 頁。故事頁需同時呈現核准的標題與段落大意文字，並讓標題與內文以不同字體區分。

## 課文理解學習單

可在繪本完成後加做學習單，例如：

- 故事順序與因果：詞語小站、事件路徑、角色需求、樹的付出與結果。
- 角色變化與主旨思考：反覆回來表格、物件交換、開頭／結尾對照、文本證據與開放式回應。

學習單保留學生可書寫的空白，問題應引導學生回到文本找證據，而不是只抄寫教師分析。

## 內容與品質原則

- 使用者提供的原文或 DOCX 是內容權威。
- 不補寫來源未支持的事件、動機、對話或事實。
- 頁數、段落順序、標題、段落大意與主旨需互相一致。
- 交付前檢查繁體中文顯示、文字可讀性、線條與淡彩比例、留白、頁面順序，以及 PDF／學習單是否完整。
