# 課文繪本化：極簡手繪黑白線條

將提供的文章、課文或 DOCX 轉化為忠於原文的繪本式視覺序列，使用極簡黑色手繪線稿與純白背景呈現。

## 適用情境

- 課文或文章的繪本化
- 段落摘要與故事地圖
- 人物、行動、物件與事件關係的視覺整理
- 教學投影片或學習材料的圖像化

## 核心原則

- 以使用者提供的來源文本為唯一內容依據。
- 先完整理解文本，再依段落或自然事件單位規劃畫面。
- 保留來源中的人物、事件、順序、引文與關鍵細節。
- 不自行新增背景事實、動機、對話、道德判斷或未被來源支持的情節。
- 使用簡單、可辨識、容易閱讀的黑白線條，提升故事結構與教學清晰度。

## 使用方式

1. 提供文章、課文或 DOCX。
2. 先完整閱讀來源並建立故事或事件脈絡。
3. 依段落或事件單位整理人物、行動、問題、變化與結果。
4. 將內容轉成來源忠實的繪本式畫面序列。
5. 檢查每個畫面是否仍符合原文，且沒有加入未經支持的內容。
